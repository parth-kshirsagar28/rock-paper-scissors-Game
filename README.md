# ✊ Rock Paper Scissors Game

A browser-based Rock Paper Scissors game built using JavaScript. The player competes against the computer, and scores are updated in real time.

## 🚀 Features

- Play against the computer
- Random computer choices
- Live score tracking
- Result messages
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📁 Project Structure

```
rock-paper-scissors/
│── index.html
│── style.css
│── script.js
```
